# 折り合い 卓上版 試し刷りデータ

すべて実寸のPDF（`pdf/`）。印刷するときは「実際のサイズ（100%）」を選び、「用紙に合わせる」は切る。

| ファイル | 用紙 | 刷り方 |
|---|---|---|
| `oriai_01_board_A3x4.pdf` | A3縦×4ページ | 両面・長辺とじで2枚。1枚目＝表A・B・C／裏 住民の広場、2枚目＝表D〜L／裏 出来事 |
| `oriai_02_board_A2.pdf` | A2横×2ページ | 印刷所向け。両面・短辺とじ（左右に裏返す） |
| `oriai_03_cards_tiles_A4.pdf` | A4×5ページ | 1〜4ページは両面・長辺とじ。灰色の線で切る。5ページ目は紙の人型コマ（片面） |
| `oriai_04_answer_sheet_A4_film.pdf` | A4 | 透明フィルム（OHPフィルム）に片面。プリンターに合うフィルムを使う |
| `oriai_05_reflection_A4.pdf` | A4×2ページ | 両面・長辺とじ |

## 地図ボード（A3×2枚版）の組み立て

1. 2枚を両面印刷する（表裏のずれは試し刷りでは気にしない）。
2. A・B・Cの紙（1枚目）を右、D〜Lの紙（2枚目）を左に、表を上にして並べる。
3. つなぐ辺の白い余白を片方だけ切り落とし、少し重ねて裏からテープでとめる。ここが折り目になる。
4. 左半分（D〜L）を下に折り込み、A・B・Cの面だけを上にして遊ぶ。

## そのほか用意するもの

- サイコロ 1個
- 封筒（角形2号）1通：表に「国からの回答　候補地の推薦への回答」と書き、回答シートと決断カード3枚を入れる
- 人型コマ 18個（木製の汎用品があればそれを使う。なければ5ページ目を切って使う）

## 作り直し

`board.html` `cards.html` `answer-sheet.html` `reflection-sheet.html` を直して `node make-pdf.mjs`。
振り返りシートのQRコードは仮置き（後で入れる）。
