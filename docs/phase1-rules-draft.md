# 折り合い フェーズ1 ルール案（半協力型・3地区）

2026-11-20 たたき台・第2版。数値はすべて仮。

第2版の変更：認知負荷を下げるため、①ルールの量を減らし、②数えたり計算したりさせない形にした（末尾の「第1版からの変更」を参照）。

## このフェーズで学ぶこと

1. **どこを除染したのか**：学校・家・田んぼ・畑・公園・森。暮らしの場所すべてが対象だった。
2. **除染した土はどこへ行くのか**：除染した土はその場（庭先・校庭）に残る。置き場がなければ、そのまま現場に置かれる。
3. **置き場が要る**：仮置場を作るには、地区の誰かの土地が要る。誰の土地を使うかで、住民の気持ちが動く。

## 設定

- プレイヤーは、ひとつの町の3つの地区の**区長**（地区の代表）。
  - **地区A（沿岸）**：原発に近い沿岸の地区。避難が続き、人がいない。公有地が多い。
  - **地区B（田畑）**：田畑の広がる地区。土が多く出る。仮置場には田んぼを借りるしかない。
  - **地区C（中心）**：役場や学校のある町の中心。人が暮らし続け、空き地がない。
- 3人は協力して**町の除染**を進める。ただし、置き場を自分の地区に作れば、自分の地区の住民が負担を負う。

## 見ればわかる盤面（数えたり計算したりさせない）

- **土の量は駒の数で見せる。** 場所カードの表に、出る土の数だけ「□」を印刷する。除染したら、その□にフレコンを置く。
- **置き場の空きはマス目で見せる。** 候補地カードの裏（仮置場の面）に、容量の数だけマスを印刷する。フレコンを置いて、埋まり具合で空きが分かる。
- **住民への響きはアイコンで見せる。**
  - 負担のある候補地カード（田んぼ・公園）の裏に、反対の住民のアイコンを1つ印刷する。
  - 引き受けた印の人型コマは、手元に並べておく。
  - 現場保管のフレコンが乗った場所カードは、そのまま「現場保管」のしるしになる。
- **色とアイコンをそろえる。**

| 表すもの | 見せ方 |
|---|---|
| 地区 | 色（A＝緑、B＝黄緑、C＝青）。カードの縁と地図の枠を同じ色に |
| 土 | 黒いフレコンだけ。土の量の□も黒い枠 |
| 反対の住民 | 赤い人のアイコン |
| 賛成の住民 | 緑の人のアイコン |
| 除染した場所 | 裏返したカード（裏は灰色・「除染済み」） |

## 準備

1. 場所カードを地区ごとに、表向きで地区の枠に並べる。
2. 候補地カードを表向き（候補地の面）で並べる。仮置場は最初はひとつもない。
3. 区長に手番カードを1枚ずつ配る。人型コマとフレコンは脇に置く。

## ラウンドの流れ（4ラウンド）

1. 進行役がボードの帯の出来事を読む。
2. 区長がA→B→Cの順に、**行動を2回**ずつ行う。
3. 4ラウンドが終わったら、町の目標を確かめる。

| ラウンド | 出来事（ボードの帯） |
|---|---|
| R1 | 2011年夏　除染が始まる。まず学校や公園、子どもの場所から |
| R2 | 仮置場を探す |
| R3 | 田んぼも借りる。それでも置き場は足りない |
| R4 | どこも満杯。終わったら、施設の候補地を推薦する |

### 行動（2種類から選ぶ）

- **除染する**：自分の地区の場所カードを1枚選び、出る土の数だけフレコンを□に置いてから、置き場を決める。
  1. 自分の地区の仮置場に空きがあれば、入れる。
  2. 他の地区の仮置場に入れてもらう。その地区の区長が「いいよ」と言ったときだけ。頼んだ区長は、脇から人型コマを1つ取って、引き受けた区長に渡す（引き受けた印）。
  3. どちらもできなければ、場所カードの上に置いたまま（**現場保管**）。

  土は1か所分まとめて動かす。最後にカードを裏返し、残ったフレコンを裏の上に戻す。
- **仮置場をつくる**：自分の地区の候補地カードを1枚裏返す。このとき、自分の地区の現場保管を、新しい仮置場に入る分だけ移す（1か所分ずつ、土の多い場所から）。

**話し合う**のは行動に数えない。いつでも他の区長と相談してよい（約束は守らなくてもよい）。

## 町の目標（全員で目指す・1つだけ）

**R4の終わりに、「まだ除染していない場所」と「現場保管がある場所」を合わせて6か所以下にする。**

- 表向きの場所カードと、フレコンが乗った場所カードを数えるだけで分かる。ボードに数え用の欄を印刷する。
- 届かなかったとき：フェーズ2のターン1（説明会）で、全地区の出目−1（「町を信用できない」）。
- 勝ち負けはない。届いたかどうかは、フェーズ2の住民の始まり方に表れる。
- 「除染しない」も「現場に置いたまま」も同じく数えるので、土を出さないために除染を止める抜け道はない。

学校の期限は、ルールから外してボードの帯の言葉にした（シミュレーションで難所にならなかったため）。

## フェーズ2への引き継ぎ

各地区の住民6人は、**反対2・条件次第2・賛成2**から始め、盤面を見て動かす。

| 盤面で見るもの | 住民の動き | 住民の声 |
|---|---|---|
| 裏返した候補地カードの、反対のアイコン | 1つにつき、1人を反対側へ | 「もう十分、土地を差し出した」 |
| 手元の「引き受けた印」が2つ以上 | 1人を反対側へ | 「よその地区の土まで」 |
| 現場保管がある場所の数 | 0〜1か所：0人、2〜3か所：1人、4か所以上：2人を賛成側へ | 「早く運び出してほしい」 |

現場保管の段階は、ボードに目盛りとして印刷する。記録用の部品はいらない。

## 手番カード（区長ごとに1枚）

**表：手番の流れ**

```
行動を2回
├ 除染する → 土を置く
│   ① 自分の仮置場  ② 他の地区（了解をもらい、人型コマを渡す）  ③ その場に置く
└ 仮置場をつくる → 自分の地区の現場保管を移してよい
話し合いは、いつでも
```

**裏：フェーズ2の早見表**（出目＋地域の事情で住民を動かす）

## 区長が悩むところ

- **土地を出すか、現場に置くか。** 土地を出せば反対が増える。出さなければ、町の目標から遠ざかる。
- **他の地区に頼むか、引き受けるか。** 地区Aは公有地が多く、空きが出やすい。B・Cから頼られる。引き受けると町の目標に近づくが、引き受けた印が2つ以上たまると住民の反対が増える。
- **何から除染するか。** 行動が足りないので、全部は終わらない。土地を出す行動に回すか、除染に回すか。

地区Aが他の地区の土を引き受けるほど、フェーズ2で「全員が受け入れる側」と明かされたときの重みが変わる。

## 史実との対応

| ゲーム | 史実 |
|---|---|
| 仮置場がないうちは、土が現場に残る | 2011年、郡山市は校庭の表土を取り除いたが、置き場が決まらず、処分場の周辺住民から強い反発があった |
| 仮置場をつくると反対が出る | 仮置場の確保には地権者や周辺住民の同意が要り、各地で時間がかかった |
| 地区ごとに仮置場を探す | 仮置場は市町村の中の地区ごとに作られることが多く、伊達市では約120か所に上った |
| 田んぼを借りる | 仮置場には公有地や借りた農地が使われ、国有林も提供された |
| 現場保管が残る | 置き場がないとき、土は除染した場所に保管された。福島市では2026年3月時点でも141か所が残る |
| 町の目標に届かない | 2013年9月、国は「2年で除染し仮置場へ」の一律の目標を見直した |

出典：郡山市の担当者による報告（jrsm.jp/shinsai/k-2kikuchi.pdf）、環境省報道発表（env.go.jp/press/17118.html）、復興庁資料（reconstruction.go.jp/topics/20121214_dai3-2-4-4.pdf）、福島県の仮置場等の状況（pref.fukushima.lg.jp/uploaded/attachment/770608.pdf）。「地区ごとに作られることが多かった」は伊達市の箇所数からの推測で、裏付けはまだ。

## シミュレーションでの確認（`sim/phase1_sim_v2.py`）

第2版のルールで、決め打ちの方針ごとに各200回。

| 区長の方針 | 町の目標の数（6以下で達成） | 達成率 | 地区A | 地区B | 地区C |
|---|---:|---:|---|---|---|
| ふつう（足りなければ土地を出す） | 5.0 | 100% | 除染5/7・反対4人・引き受け4回 | 除染5/7・反対5人 | 除染7/7・反対3人 |
| 地区Aが引き受けを断る | 6.8 | 22% | 反対3人 | 反対6人 | 現場保管2.8か所 |
| 地区Bだけ土地を出し渋る | 9.5 | 0% | 引き受け6.5回 | 現場保管約5か所 | 現場保管約3か所 |
| 全員が土地を出し渋る | 14.8 | 0% | – | – | – |

「反対」は、フェーズ2の始まりで反対側にいる住民の人数（6人中）。

- 町の目標は、誰か1人が協力をやめると届かなくなる。半協力型の「押しつけ合い」が効いている。
- ふつうに進めると、地区AとBは除染が5/7で終わる。行動の半分近くが、仮置場づくりと引き受けに回るため。
- 地区Bは田んぼを3枚とも貸し、反対が最も多くなりやすい。地区Aは引き受けが重なって反対が増える。
- CPUの方針は単純な決め打ちで、人どうしの交渉は表せていない。第1版の確認は `sim/phase1_sim.py`。

## 第1版からの変更

| 第1版 | 第2版 | ねらい |
|---|---|---|
| 行動は「除染する・仮置場をつくる・運ぶ」の3種類 | 「除染する・仮置場をつくる」の2種類。置き場は除染のときに決め、仮置場をつくったときに現場保管を移せる | 手順を1つ減らす |
| 人手は「行動を1回増やす」と「お礼」の2つの使い道 | 引き受けた印だけ。最初は持たず、頼んだ区長が脇から渡す | 損得の計算をなくす |
| 町の目標は「学校の期限」と「現場保管6か所以下」の2つ | 「未除染＋現場保管が6か所以下」の1つ。学校は帯の言葉に | 目標を1つにし、除染しない抜け道もふさぐ |
| 引き継ぎは「土を3以上引き受けた」「現場保管2か所につき1人」 | 引き受けた印の数、現場保管の目盛り、カード裏のアイコンで読む | 盤面を見るだけで分かる |
| ― | 場所カードに土の□、候補地カード裏に容量のマス、手番カード、色とアイコンの統一 | 数えたり計算したりさせない |

## まだ決めていないこと

- 引き受けた印（人型コマ）に、引き受けた区長にとっての得がない。引き受ける理由は町の目標だけになる。試遊で、引き受けが起きるかを確かめる。
- フェーズ1に運の要素がない。CPUだけで遊ぶと毎回同じ結果になる（人どうしなら交渉で変わる）。出来事に小さな揺らぎ（大雨で仮置場の工事が遅れる、など）を入れるか。
- ブラウザ版 `oriai-v2.1-testplay.html` は第2版を反映済み。次の2点は仮に決めている。
  - 他の地区に断られたら、ほかの置き場を選び直す（行動は除染の1回のまま）。
  - 2地区以上が受け入れれば、町として受け入れる。
- ブラウザ版のCPUは、置き場が足りなければR1から田んぼや公園も仮置場にする。CPUだけで遊ぶと、町の目標の数はちょうど6か所（seedによらず同じ）。
